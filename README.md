# NLP-Based Automated Spam Detection System

An end-to-end Natural Language Processing (NLP) system built with Python, Scikit-Learn, and NLTK to classify messages as Spam or Ham.

## 📌 Project Overview
Spam detection is a classic NLP task. This project preprocesses raw text, extracts numerical features using TF-IDF Vectorization, and trains Supervised Machine Learning algorithms (Naive Bayes, Logistic Regression, SVM) to detect fraudulent messages.

## 📂 Project Structure
- `source_code.py`: Complete Python pipeline
- `requirements.txt`: Required dependencies
- `confusion_matrix.png`: Model evaluation plot
- `report/`: Complete PDF project report

## 📊 Key Results
- **Multinomial Naive Bayes Accuracy:** 97.13%
- **Precision:** 98.44%
- **F1-Score:** 88.25%
